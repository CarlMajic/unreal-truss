# ShowCaster Visual Style Guide

## Brand Core

ShowCaster is a live-event build and previsualization tool by Majic Productions.

Core line:

**Build the show. Cast the vision.**

The visual identity should feel like:

- vintage film projection
- client-ready show preview
- cinematic event design
- modern Unreal Engine production software
- premium but practical live-event workflow

The brand should not feel like a generic construction tool, truss tool, CAD utility, or fantasy magic product.

## Logo Direction

The ShowCaster logo is based on a stylized vintage film projector:

- two reels
- simple projector box/body
- oversized front lens
- charcoal gray body
- orange lens/accent details
- bold simplified silhouette
- extreme wide-angle character is welcome

The logo should pair naturally with the Majic Productions brand, whose logo is inspired by a stylized Aura moving-head light.

Logo language:

- projector/source of the vision
- show image being cast for the client
- cinematic reveal
- presentation and previsualization

Avoid making truss the logo symbol. Truss is infrastructure; clients care about seeing the finished show.

## Color Palette

Primary colors:

- Charcoal gray: `#2f3133`
- Orange: `#f26a21`
- Warm off-white / projection screen white: `#f7f3ec`

Use orange as:

- projector lens glow
- active highlight
- grease-pencil annotation
- call-to-action accent
- selected UI state
- film leader/frame accent

Use charcoal as:

- primary typography
- icon body
- structural UI
- dark background sections

Avoid dominant blue, purple, neon rainbow, beige-heavy palettes, and generic tech gradients.

## Texture And Mood

The page and generated images can lean into subtle vintage projection details:

- film grain
- dust specks
- light scratches
- projected light falloff
- soft screen texture
- film strip edges
- contact sheet frames
- faint leader marks
- warm projector glow

Keep these details subtle. The style should feel premium and cinematic, not dirty, damaged, spooky, or retro-kitsch.

## Page / Image Atmosphere

The overall look should combine:

- modern event software
- vintage film projection
- client presentation room
- live-event previsualization
- charcoal/orange brand system

Good imagery:

- ShowCaster logo projected onto a warm off-white screen
- event layout shown as a projected image
- film strip frames containing build categories
- client-review projection scenes
- Unreal-style event plans with orange markup
- stage, lighting, scenic, decor, bars, and tables shown as projected concepts
- clean software UI framed like projected film

## Hero Image Direction

Hero images should lead with the ShowCaster logo and projection concept.

Recommended hero:

- dark charcoal or warm off-white projection environment
- ShowCaster logo large and readable
- subtle orange lens glow
- projected event layout or stage plan hinted in the background
- film grain and dust in the projected light
- tagline visible as normal page text or clean graphic text

Avoid making the hero only a truss scene. Truss can appear as one event element, but the hero should communicate complete event builds and client-facing visualization.

## Section Image Concepts

### ShowCaster Hero Projection

A stylized vintage projector casting the ShowCaster identity onto a warm screen, with subtle dust, scratches, orange lens glow, and faint live-event layout geometry in the projection.

### Film Strip Build Categories

A horizontal film strip/contact sheet with frames for:

- stage
- truss/rigging
- lighting
- scenic walls
- bars
- tables/decor

Each frame should feel like a projected concept or event layout preview.

### Client Review Projection

A premium client-review scene where an event design is projected onto a screen or wall. The mood should feel like a professional design presentation, not a movie theater.

### Vintage Film Event Layout

An Unreal-style event floor plan, stage layout, or scenic build shown through a vintage film/projection overlay with charcoal and orange annotations.

### Projected Software UI

A clean ShowCaster build UI or Unreal placement workflow shown as a projected frame, with orange highlights and subtle film texture.

## Typography Direction

ShowCaster wordmark:

- bold geometric sans serif
- readable
- charcoal `Show`
- orange `Caster`
- slight projected/perspective treatment is allowed for the logo, but not so much that it hurts readability

Supporting text:

- clean modern sans serif
- mostly charcoal
- orange only for emphasis
- avoid decorative fantasy fonts

## Layout Direction

GitHub README / project page style should resemble a landing page:

- full-width logo or hero image at the top
- centered product name and tagline
- badge row or small product metadata row
- two-column story sections
- film-strip/contact-sheet feature blocks
- compact tables for build systems and statuses
- long project logs collapsed below the polished intro

Keep all technical information, but make the top of the page feel client-facing and brand-forward.

## What To Avoid

Avoid:

- truss as the main identity symbol
- fantasy wand or spell imagery
- neon nightclub visuals
- heavy purple/blue gradients
- generic SaaS dashboard style
- cluttered film scratches that reduce readability
- horror/old damaged film mood
- overly literal movie theater imagery
- old clipart projector
- photorealistic projector product shots
- unreadable skewed text
- removing technical project information from documentation
